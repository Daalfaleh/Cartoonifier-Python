# Cartoonifier Python

A desktop image-processing tool that converts a selected photograph into a cartoon-style image. It uses OpenCV filters and edge detection, provides a Tkinter interface, previews processing stages, and can save the result.

## Requirements

```bash
pip install opencv-python easygui numpy imageio matplotlib pillow
```

## Run

```bash
python cartoonifier-python-project.py
```

Choose an image, let the application generate the cartoon effect, then use the save action to export it.
